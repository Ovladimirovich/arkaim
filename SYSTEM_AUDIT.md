## 2. КРИТИЧЕСКИЕ ПРОБЛЕМЫ (исправить в первую очередь)

### 2.1 Тесты auth-пакета — 0% покрытия

auth/ — единственный новый пакет, полностью не покрытый тестами:
- `api_keys.py` (генерация/верификация)
- `tokens.py` (JWT issue/verify)
- `rbac.py` (role hierarchy, get_current_user)
- `routes.py` (все /auth/* эндпоинты)
- `users.py` (UserStore — upsert, get_user, set_role)
- `oauth/*.py` (Telegram/Google верификация)

**Риск:** регрессия в auth-логике не будет обнаружена до продакшена.

### 2.2 sys.path hack в book_routes.py

```python
_BOOK_CORE = Path(...) / "ARKAIM_DIGITAL_CONSCIOUSNESS" / "CORE"
sys.path.append(str(_BOOK_CORE))
```

- Хрупкий: сломается при переименовании/перемещении папок
- Может вызвать shadowing системных пакетов
- Создаёт неочевидный порядок разрешения импортов

### 2.3 Module-level синглтоны (9 штук в book_routes.py)

```python
layers = ConsciousnessLayers()
retriever = BookRetriever()
keeper = KeeperAgent()
herald = HeraldAgent()
# ... ещё 5
```

- Невозможно подменить для тестов
- Нет контроля жизненного цикла
- Создаются при старте Core независимо от того, нужны ли

### 2.4 Дублирование глобального состояния

| Что | Где | Проблема |
|---|---|---|
| GraphEngine × 3 | keeper.py, api_routes.py, book_routes.py | Разные in-memory копии, не синхронизированы |
| LLM-клиент × 2 | ADC llm_client, runtime providers | Разные пути к LLM, разная обработка ошибок |
| UserStore × N | auth/routes.py, core/auth.py, gateway/auth.py | Каждый запрос создаёт новый UserStore с новым aiosqlite соединением |

### 2.5 Gateway circuit breaker — не thread-safe

```python
_CORE_FAILURES = 0  # int — модульный глобал
_CORE_BLOCKED_UNTIL = 0.0
```

Модифицируется в async-функциях без блокировки. При конкурентных запросах возможны гонки.

### 2.6 Нет мониторинга падений

`health_monitor.py` существует, но не подключён. Если Core упадёт ночью — админ узнает только утром.

## 3. АРХИТЕКТУРНЫЕ ПРОБЛЕМЫ (средний приоритет)

### 3.1 Связность «двух миров»

Runtime (FastAPI-микросервис) и ADC (книжный движок) взаимно импортируют друг друга:
- Runtime → ADC: `book_routes.py` импортирует всё из CORE/
- ADC → Runtime: `book_os/api_routes.py` импортирует `auth/rbac`

**Последствие:** нельзя запустить ADC отдельно от Runtime.

### 3.2 Среднее покрытие тестами (~30-35%)

| Зона | Покрытие |
|---|---|
| identity (sanitizer/policy/contract) | 100% ✅ |
| memory (store/leads) | 100% ✅ |
| integrations/telegram | 80% ✅ |
| core/orchestrator | 70% ✅ |
| core/genome | 60% ✅ |
| gateway (proxy/rate_limit) | 40% ⚠️ |
| auth | 0% ❌ |
| core/providers (конкретные) | 0% ❌ |

### 3.3 Нет миграций БД

auth.db и memory.db создаются автоматически через `CREATE TABLE IF NOT EXISTS`. При изменении схемы — ручное вмешательство.

### 3.4 Pydantic deprecation warnings

```python
question: str = Field(..., description="...", example="...")
# Warning: Using extra keyword arguments on Field is deprecated
# → нужно: json_schema_extra={"example": "..."}
```

3. **DI-рефакторинг** — заменить module-level синглтоны на FastAPI Depends с lifespan-фабрикой
